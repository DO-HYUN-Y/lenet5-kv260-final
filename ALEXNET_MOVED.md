# AlexNet project moved

The complete batch-one AlexNet M8xN128 graph-integration project has moved to
[`DO-HYUN-Y/alexnet-kv260-final`](https://github.com/DO-HYUN-Y/alexnet-kv260-final).

XSim/Vivado scripts and reports, plus the timing-clean KV260 `.bit` and `.xsa`
release artifacts.  Its first standalone commit was split from this
repository's AlexNet checkpoint `56fb4a3947b65672aef36e09d89f29d4e25e7b66`.
